# Skill 系统实现状态

更新时间：2026-09-06。

已完成首版统一协议、清单校验、技能启停、任务与调用日志、审批摘要绑定、取消、事件续传、本地认证、Ollama 工具循环及独立会话历史。新增 Skill 不需要修改 Agent 主循环；Python 与 Swift 执行器使用同一调用信封和错误码。

网络搜索 Skill 已接入并默认启用，提供 `web.search` 和 `web.fetch_page` 两个只读动作。模型依据消息中的当前时间自动判断是否联网，可设置时间范围、改写一次偏题查询、读取少量直接来源并在回答中保留链接。搜索使用 Bing RSS，并以 DuckDuckGo HTML 作为后备；网页读取逐跳校验重定向和 DNS，拒绝本机、内网、保留地址、登录凭据及非标准端口，响应限制为 1MB。

macOS 原生宿主已支持 16 个动作：应用查找、运行列表、打开、切换、正常退出；日历列表、日程查询、新建、修改、删除；提醒列表、提醒查询、新建、修改、完成、删除。日历和提醒事项写操作始终展示具体预览并等待确认，执行后读回验证。重复日程和重复提醒的修改、强制退出、任意脚本执行均被拒绝。

资源配置面向 M5 Pro、24GB 统一内存：最多暂存 4 个后台任务，9B 推理严格串行，网络请求最多并发 2 个；审批等待、原生执行和结果核验不占推理锁；上下文 8K、单轮最多生成 768 token；每次最多 8 轮推理、16 次工具调用；单页正文默认 7000、最多 9000 字符，网页响应最多 1MB；系统操作和实时查询跳过无关记忆检索；技能指导按 1200 字符截断；反馈模型默认关闭；9B 模型 keep-alive 两分钟；原生宿主断线重连指数退避到 30 秒；应用目录索引只构建一次且限制扫描深度。

对话界面已支持后台运行：发送后输入框立即恢复，每个请求独立显示队列、记忆检索、模型等待、规划、预览、审批、执行和核验状态，并每 4 秒刷新等待时长。审批与取消均绑定到具体 run，多个任务不会串线。会话消息使用 SQLite 原子追加，后台任务乱序完成不会覆盖其他回答；任务、事件和 Skill 调用序列可通过 `/runs` 与 `/runs/{id}/calls` 查询。

任务界面使用可开关的右侧 Inspector 分栏，主对话流只保留消息。工具栏显示活动任务数量，待确认操作出现时自动展开分栏。任务按运行中和最近完成分组，使用中文状态、颜色、请求摘要与折叠式 Skill 调用序列；操作预览、确认、拒绝和独立取消都在分栏中完成。界面使用原生 SwiftUI 惰性列表，不增加模型、轮询器或高频动画。

已验证：20 个 Python 测试（含网络解析、网页提取、内网拒绝、默认启用偏好、审批等待期间运行第二个任务、任务上限和并发会话追加）、4 个 Swift 测试、应用签名和 plist、真实网络搜索与 9B 自动路由、无副作用 Ollama tool-call 探测、原生 Safari 查找、自然语言运行应用查询、计算器打开和正常退出。日历与提醒事项真实数据未由自动测试访问，需用户在测试日历/提醒列表中完成权限和写入验收。

后续范围仍包括：真实语音输入输出、重复事项编辑范围、Shortcuts、Apple Events、Accessibility 界面操作、后台常驻和第三方 MCP/插件隔离。最低 macOS 14 已通过 SDK 编译，当前实机验证环境为 macOS 26.4。
